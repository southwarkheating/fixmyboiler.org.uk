Before you look up a code

  1. Write the code down exactly as it appears, including any letters.
  2. Check the pressure gauge. Low pressure causes more lockouts than anything else.
  3. Check your gas supply: does the hob work, and does your meter have credit?
  4. In freezing weather, check the condensate pipe outside. See our frozen condensate pipe guide.
  5. Reset the boiler once. If the same code comes back, stop and book a repair.
Safety first. Never take the casing off your boiler. Only a Gas Safe registered engineer should work inside it. If you smell gas, call 0800 111 999.

Codes that mean stop and call

Some codes point to faults that should not be reset over and over: false flame, flue faults, gas valve faults and repeated overheating. If you see one of these, switch the boiler off and book a repair visit.
